Getting a national health-data network certified

Under TEFCA, a Qualified Health Information Network (QHIN) must pass the Sequoia Project RCE conformance suites before it can exchange records with other networks. I led conformance for the Oracle Health Information Network.

# problem

Every XUA transaction has to behave identically across independent partner networks. Testing that by hand is slow, and partner test windows are scarce.

# what I built

  • A QHIN Simulator aligned to the Sequoia test specs and built for CI/CD. It cut manual testing by about 30%.
  • Reusable security and transport validation scripts for gameday testing, saving about a day per engineer.
  • SMART on FHIR v2 authorization flows so third-party apps can launch securely against network APIs.

# result

The network passed every RCE certification suite. I directed external participant testing so that every XUA transaction was validated end to end with partner networks.

participant app ──SMART v2 / OAuth──▶ [ OHIN gateway ] ──XUA──▶ [ partner QHIN ]
                                          │                                  │
                                          └──────▶ [ QHIN Simulator ] ◀──┘
                                                   conformance in CI/CD
